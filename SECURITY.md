# Security Policy

## Reporting a vulnerability

Use GitHub Security Advisories as the only reporting channel:

1. Open this repository's **Security** tab.
2. Choose **Advisories**.
3. Select **Report a vulnerability**.

Do not open a public issue for a security problem. Do not include live
credentials, tokens, or private data in a report; describe the issue and use
redacted examples where needed.

## Supported versions

Only the latest released version receives security fixes.
